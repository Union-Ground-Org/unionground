# iOS device-drill runner

The repository-owned XCUITest channel for the G6 iOS physical drill: hierarchy
dump, tap, text entry, custom-scheme hand-off, screenshots and the device
settings the matrix rows need.

- Runbook, prerequisites, commands and evidence layout:
  [`docs/mobile/ios-xcuitest-drill-runner.md`](../../../docs/mobile/ios-xcuitest-drill-runner.md)
- Row contract: [`row-manifest.json`](row-manifest.json)
- Recipe: [`apps/mobile/scripts/ios-device-drill.mjs`](../scripts/ios-device-drill.mjs)
- Regression test: `tests/ios-xcuitest-drill-runner.test.js`

`apps/mobile/ios` is generated by `expo prebuild` and is ignored by Git, so this
target lives beside it rather than inside it. It attaches to the installed
application by bundle identifier and needs no test host, so `expo prebuild`
never rewrites it and it needs no integration into the generated workspace.
