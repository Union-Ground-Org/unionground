# Union Ground crawler policy (2026-10-14; access rule tightened
# 2026-10-19).
#
# No automated agent may fetch this site, for any purpose, except the general
# search engines and link-preview fetchers named in the second group below,
# which may fetch the public pages only to index them for search results or to
# show a link preview. "Any purpose" includes fetching a page to answer a
# question, to summarize it, to look something up or to give someone
# information about it, as well as crawling, scraping, AI training, AI
# retrieval and building datasets. It applies whether or not the agent's
# user-agent token appears below, and whether a person or a company sent it.
# Any other automated collection of this site or the Union Ground apps is
# not permitted without written permission. See /terms on this site.
# This applies to every AI provider and agent,
# including OpenAI (ChatGPT, GPTBot), Anthropic (Claude), Google (Gemini),
# Microsoft (Copilot), Meta AI, Amazon, Apple Intelligence, Perplexity, xAI
# (Grok), Mistral, Cohere, ByteDance, DeepSeek and Common Crawl, and to any AI
# agent, agentic browser or coding agent acting for a person or a company,
# whether or not its user-agent token appears below. Every response also carries
# "X-Robots-Tag: noarchive, noai, noimageai" and "TDM-Reservation: 1", and
# /.well-known/tdmrep.json reserves text-and-data-mining rights; with the
# Content-Signal line (ai-train=no) they reserve training rights.
#
# The access rule is the Allow and Disallow lines in the groups below. The
# Content-Signal line is a reservation of rights about how content may be used.
# It is not the
# access rule, and an agent that reads only Content-Signal has not been given
# permission to fetch a disallowed path.
#
# The access rule is the Allow and Disallow lines in the groups below: every
# agent is denied the whole site unless a group names it. The Content-Signal
# line is a reservation of rights about how content may be used. It is not the
# access rule, and an agent that reads only Content-Signal has not been given
# permission to fetch anything.
#
# Content Signals Policy (https://contentsignals.org/), the meaning of the
# Content-Signal lines in the groups below:
#
# As a condition of accessing this website, you agree to
# abide by the following content signals:

# (a)  If a content-signal = yes, you may collect content
# for the corresponding use.
# (b)  If a content-signal = no, you may not collect content
# for the corresponding use.
# (c)  If the website operator does not include a content
# signal for a corresponding use, the website operator
# neither grants nor restricts permission via content signal
# with respect to the corresponding use.

# The content signals and their meanings are:

# search: building a search index and providing search
# results (e.g., returning hyperlinks and short excerpts
# from your website's contents).  Search does not include
# providing AI-generated search summaries.
# ai-input: inputting content into one or more AI models
# (e.g., retrieval augmented generation, grounding, or other
# real-time taking of content for generative AI search
# answers).
# ai-train: training or fine-tuning AI models.
